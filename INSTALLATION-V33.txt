40×20 COMPACT
- suivi réduit mais lisible ;
- code-barres optimisé en hauteur ;
- vraie marge blanche latérale ;
- ASIN + code en gras ;
- description jusqu'à 2 lignes ;
- moins de données Bluetooth qu'en 40×30, donc impression plus rapide.

40×70 LONG
- 40 mm de largeur × 70 mm de hauteur : compatible M110 ;
- suivi plus grand ;
- code-barres nettement plus haut ;
- vraie marge blanche latérale ;
- ASIN/code agrandis ;
- description très lisible jusqu'à 6 lignes ;
- pré-test Bluetooth dès 4 étiquettes ;
- sous-lots limités automatiquement à 3 étiquettes maximum ;
- pause de vidage tampon renforcée entre sous-lots.

50×30
- conserve la marge de sécurité du code-barres déjà validée.
